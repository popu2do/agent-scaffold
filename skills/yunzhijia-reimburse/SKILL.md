# 云之家报销自动化填表 (Yunzhijia Reimburse)

用于自动化向云之家（Kingdee CloudFlow）日常费用报销审批单中批量填入发票明细。

## 核心架构与安全准则

1. **响应式数据直驱**：通过浏览器执行上下文直写云之家明细表 Vue 组件（`DetailField`）的内部 `values` 数组，并触发 `calcArithmetic()` 联动计算，避免模拟鼠标键盘点击带来的卡顿与弹窗错位。
2. **上下文动态继承**：若当前报销单中已手动填入第一行，自动提取其“研发项目”与“承担部门”并继承至所有增补行；若单据全空，则回退读取本地业务配置。
3. **业务隔离与零敏感信息泄露**：
   - 技能规范与脚本完全脱敏，不硬编码任何具体企业名、研发项目代码或部门名称。
   - 真实业务配置放置于工作区根目录的私有文件 `.yunzhijia-reimburse.json`（已被 `.gitignore` 忽略），技能本体可安全发布与开源。
4. **终态安全边界**：**严格禁止自动点击“提交”按钮**。技能的执行终点限定为：数据填入就绪、大写总金额校验无误、输出明细核对清单与页面截图，最终提交保留人工确认。

## 配置规范

业务默认项配置格式参考 `assets/config.template.json`：

```json
{
  "defaultProject": {
    "name": "SAMPLE-PROJECT-NAME",
    "id": "52",
    "number": "SAMPLE-PROJECT-CODE"
  },
  "defaultDepartment": {
    "name": "SAMPLE-DEPT-NAME",
    "id": "2",
    "number": "002"
  },
  "categoryMappings": [
    {
      "keywords": ["打车", "出行", "交通", "网约车", "出租车"],
      "type": "加班交通费",
      "id": "3",
      "number": "08.01",
      "defaultReason": "加班打车费"
    },
    {
      "keywords": ["餐", "工作餐", "外卖", "餐饮"],
      "type": "加班餐费",
      "id": "1",
      "number": "04.02",
      "defaultReason": "加班餐费"
    }
  ]

```

配置加载优先级：
1. **页面已有首行动态继承（优先级最高）**：若报销单已填写第一行，自动提取并继承其项目与部门编码。
2. **本地私有配置 `config.json`**：存放于技能目录内，已加入 `.gitignore`，包含本地真实业务默认值，供本地反复调用。
3. **工作区私有配置 `.yunzhijia-reimburse.json`**：工作区根目录备用私有配置。
4. **缺省引导**：若均无配置且表格为空，技能提示用户根据 `assets/config.template.json` 补全。

## 执行工作流

### 步骤 1：解析发票文件
1. 扫描用户指定的发票目录，按命名规则 `YYMMDD_金额_服务方.pdf` 提取日期与金额。
2. 转换为标准日期格式 `YYYY-MM-DD`。
3. 根据文件名或销售方关键词自动匹配费用类型与事由（如含“出行/叫车”匹配为“加班交通费”）。
4. **比对去重**：读取当前云之家报销单已存在的行（日期+金额），自动跳过已填发票，仅提取待增补项。

### 步骤 2：生成注入载荷
构建标准明细项数组：
```javascript
const newItems = [
  {
    date: '2024-05-15',
    amount: '38.50',
    reason: '加班打车费',
    typeObj: { id: "3", name: "加班交通费", number: "08.01" }
  }
];
```

### 步骤 3：双通道执行

#### 通道 A：OpenCLI 自动注入（首选）
1. 确认 OpenCLI 守护进程与扩展就绪。
2. 将 `scripts/yunzhijia-injector.js` 与载荷打包后，通过 OpenCLI 执行注入。
3. 注入脚本会自动从报销单第 1 行继承项目与部门信息，追加数据并重算总金额。

#### 通道 B：控制台脚本降级（兜底）
当 OpenCLI 未就绪或多标签页焦点无法定位时，**必须立即生成一段自包含的单行 JavaScript 脚本**输出给用户：
- 指引用户在云之家页面按 `F12` 进入 **Console（控制台）**。
- 粘贴代码并回车，一秒内完成表格追加与金额重算。

### 步骤 4：汇总与核对
1. 校验明细累加金额与发票清单总额是否一致。
2. 读取表单合计容器 `#Ac_0`，核对小计金额与中文大写总额。
3. 截取表单页面输出给用户核对，提示用户自行点击“提交”。
