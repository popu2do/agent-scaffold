## 快速通道流程（主控+并行+独立验证）

### 适用场景

| 任务类型 | 简化策略 | 条件 |
|---------|---------|------|
| 纯 Bug 修复 | 跳过并行拆分，单 Worker 执行 | 问题明确、影响范围小 |
| 配置调整 | 跳过并行拆分，单 Worker 执行 | 配置项已存在、仅修改值 |
| 文档更新 | 仅派发文档 Worker + 独立复核 | 无代码变更 |

### 简化流程

**Bug 修复/配置调整**：

```
主控冻结目标
    ↓
单 Worker 实现（Agent3）
    ↓
独立验证（Agent2 或 Agent1）
    ↓
主控汇报
```

**文档更新**：

```
主控冻结目标
    ↓
文档 Worker（Agent4）
    ↓
独立复核（Agent1）
    ↓
主控汇报
```

### 派发模板

复用 full-cycle.md 派发模板，但保持“冻结目标→执行→独立验证→汇报”最小闭环。
</process>

<success_criteria>
快速通道成功的标志：

- 任务确实符合简化条件
- 必要阶段全部完成
- 测试通过（如涉及代码）
- 文档已更新（如涉及文档）
</success_criteria>
